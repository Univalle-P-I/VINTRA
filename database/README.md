# Base de datos

Este directorio está reservado para los artefactos ejecutables de persistencia: migraciones, scripts y configuración específica de la base de datos. Actualmente PostgreSQL se declara como servicio en [`../docker-compose.yml`](../docker-compose.yml), mientras que el diseño y diccionario disponibles están en [`../docs/base-de-datos/`](../docs/base-de-datos/).

No hay migraciones ni scripts propios en esta carpeta todavía; añadirlos aquí cuando el modelo se implemente.
