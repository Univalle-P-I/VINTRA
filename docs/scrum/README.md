# Scrum

Guía para documentar el trabajo funcional y los acuerdos de planificación.

## Debe publicarse aquí

- historias de usuario y criterios de aceptación, o enlaces a `modelado/`;
- definición de terminado y reglas de priorización;
- acuerdos de las reuniones que cambien el alcance o la forma de trabajar;
- relación entre issues, entregables y Pull Requests;
- decisiones pendientes con persona responsable y fecha de revisión.

## Estado

- Estado: `Borrador`
- Responsable: Célula Scrum
- Pendiente: publicar las historias de usuario y sus criterios de aceptación.
