# Módulo Frontend - VINTRA

## Descripción General

El cliente web de VINTRA está desarrollado con **React** sobre **Vite**,
diseñado para ofrecer una interfaz dinámica, escalable y optimizada.
Se conecta de manera asíncrona con el servidor mediante una API REST
utilizando la librería **Axios** para las peticiones HTTP.

## Stack Tecnológico

### Herramientas Principales

- **Librería de Interfaz**: React
- **Empaquetador**: Vite
- **Cliente HTTP**: Axios
- **Lenguaje**: JavaScript (ES6+) / JSX

### Justificación de Selección

- **React**: Permite construir una interfaz organizada por componentes.
- **Vite**: Ofrece una velocidad superior en desarrollo local.
- **Axios**: Simplifica las peticiones HTTP con manejo de promesas.
